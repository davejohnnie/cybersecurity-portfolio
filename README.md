## Featured Projects

### Phishing Awareness Simulation using GoPhish

Designed and implemented a phishing awareness campaign using GoPhish within a Kali Linux virtual environment. The project covers email template creation, SMTP configuration, landing pages, recipient management, campaign execution, credential capture within an authorised laboratory environment, and campaign reporting.

📁 Open the **Phishing Awareness Simulation using GoPhish** folder.

---

### System Monitoring with Prometheus, Grafana and Node Exporter

Built a complete monitoring stack using Node Exporter, Prometheus, and Grafana. The implementation demonstrates system metric collection, Prometheus configuration, and the creation of Grafana dashboards for monitoring CPU usage, memory utilisation, disk usage, network traffic, and running processes.

📁 Open the **System Monitoring with Prometheus, Grafana and Node Exporter** folder.

---

### Vulnerability Assessment using Greenbone Community Edition

Configured Greenbone Community Edition (OpenVAS) within a Kali Linux laboratory environment and performed authorised vulnerability assessments against a Windows host machine. The project includes scan configuration, target creation, vulnerability analysis, and report generation.

📁 Open the **Vulnerability Assessment using Greenbone Community Edition** folder.
